# v1.3.0 — scene tools stop losing your unsaved work

An audit of every tool that takes a `scene_path` ran 732 cases against Godot 4.7
with a human edit already in the open scene. It found 13 families of bugs across
77 tools. The worst ones reported success while the change was lost, or quietly
threw away what the user had not saved yet. This release fixes all of them.

## What was going wrong

- **Inactive tabs fell back to disk.** The scene helper only knew the focused tab.
  Editing a scene that was open in another tab loaded it from disk instead, so the
  agent's change lived outside the editor's tree and undo, and the next human save
  wiped it. Open-but-inactive targets are now refused with a clear message.
- **Previews were not previews.** Several tools wrote files, created folders or
  mutated shared Resources even with `dry_run`. Previews now work on an isolated
  copy of the unsaved editor state.
- **Shared resources changed only in memory.** Editing a `.tres` through a closed
  scene changed it in RAM but saved only the scene, so the edit vanished on the
  next start. The change is now stored as a copy inside that scene. This is a
  behavior change: the shared file itself is no longer modified.
- **Undo was incomplete.** Animation keys, state machine transitions, script
  exports and bone poses now come back fully on undo, and a failed call no longer
  leaves a half-applied action in the history.
- **Silent overwrites.** Creators and resource export refuse to replace an
  existing file unless asked to.
- **Edits to inherited or instanced children** that cannot be saved are refused
  instead of disappearing when the scene is packed.

## Also in this release

- `read_scene` has a compact rows format and a 500-node default budget with
  explicit truncation.
- `find_tools` understands common Spanish terms and ignores accents.
- The transport fails pending requests at once on bad frames, failed sends or an
  incomplete handshake, instead of letting them time out.

## Cost

The default surface every request pays goes from 9,533 to 9,732 tokens (+2%),
mostly from the new `read_scene` options.

## Verified

329 Node tests (with the editor e2e suite on Godot 4.7), 822 GDScript logic tests,
and a packed-tarball install into a fresh project. Not covered: the windowed
render test and manual use of the editor UI.

Restart the Godot editor after updating: the addon's base classes changed.
